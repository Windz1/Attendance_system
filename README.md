# 杭科易网通物联网技术学院考勤系统

一个面向学院班级考勤场景的管理平台，将**学生与班级管理、考勤计划、移动端点名、记录追踪和统计分析**串联起来，帮助管理员与部员协同完成日常考勤。

## 项目简介

传统点名工作往往需要反复整理名单、分配任务和汇总结果。本项目以考勤计划为中心：管理员先维护班级与学生信息并安排点名，系统按计划生成任务，部员在移动端完成点名，最终由管理员查询记录和查看统计。

适用于需要按班级、按日期和时间段组织考勤的学院或团队。

## 核心功能

| 模块 | 能做什么 |
| --- | --- |
| 学生与班级 | 维护学生档案和班级信息；支持 Excel 名单导入、模板下载，以及重复学号的跳过或更新。 |
| 考勤计划 | 设置适用班级、生效日期、执行星期和点名时段；系统自动生成对应的点名任务。 |
| 移动端点名 | 部员查看待办任务，按学生标记考勤状态，并可上传班级照片。 |
| 记录与统计 | 按班级、日期和状态检索考勤记录，导出数据，查看班级考勤情况与状态分布。 |
| 人员与权限 | 区分管理员和部员角色，管理部员账号及其负责的班级。 |

一次考勤的典型流程：

**导入学生名单 → 创建考勤计划 → 自动生成任务 → 部员移动端点名 → 管理员查看记录与统计**

## 角色分工

- **管理员**：维护基础数据和考勤计划，分配部员负责的班级，查看与导出考勤结果。
- **部员**：查看本人负责班级的任务，在规定时段内完成点名与提交。

## 技术栈

| 前端 | 后端 | 数据存储 |
| --- | --- | --- |
| Vue 3、Vite、Element Plus | Java 17、Spring Boot、MyBatis-Plus、JWT、EasyExcel | MySQL |

项目代码分为 [`attendance-frontend/`](attendance-frontend/) 和 [`attendance-backend/`](attendance-backend/) 两部分，便于分别开发与部署。界面同时提供管理后台和适合手机使用的点名页面。

## 项目说明

- 仓库不包含真实学生名单、生产数据库或可直接使用的演示账号。
- 考勤记录默认只保留最近一个月；实际使用前应确认数据保留策略符合需求。
- [`schema.sql`](attendance-backend/src/main/resources/sql/schema.sql) 用于**全新空数据库**初始化，包含删表语句，不可用于已有数据的系统升级。

本项目持续围绕实际考勤流程完善功能，欢迎交流使用中的问题与改进建议。
